# MelodyAI – AI Music Generation

MelodyAI is an AI-powered music generation application that uses an LSTM neural network to learn musical patterns and generate new piano melodies.

## Features

- AI-based music generation using LSTM.
- Customizable music length and creativity.
- MIDI music generation.
- WAV audio conversion and playback.
- Download generated music.
- Interactive Streamlit interface.

## Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- PrettyMIDI
- SciPy
- Streamlit

## Dataset

MAESTRO MIDI Dataset.

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/shzz09/MelodyAI.git
cd MelodyAI
```

**2. Install dependencies**

```bash
pip install numpy tensorflow pretty_midi streamlit scipy
```

**3. Run the application**

```bash
streamlit run app.py
```

## Output

- MIDI file – Generated musical notes.
- WAV file – Generated audio for playback.
